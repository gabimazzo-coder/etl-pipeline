# etl-pipeline
Pipeline ETL de Optimización y Carga EficienteEste repositorio contiene un pipeline de ingeniería de datos básico desarrollado en Python para demostrar la extracción, transformación y almacenamiento optimizado de datos con fines analíticos y de Machine Learning.
Estructura del Proyectosrc
extraction.py:
Lógica para la lectura de fuentes y optimización preventiva de tipos de datos en memoria (downcasting).src
transformation.py:
Módulo independiente con algoritmos de limpieza, estandarización de columnas y control de nulos.
main.py: Orquestador principal que ejecuta de punta a punta el pipeline.
